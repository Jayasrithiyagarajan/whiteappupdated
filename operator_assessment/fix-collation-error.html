🔧 Fix Collation Error

❌ Error Encountered:

Illegal mix of collations (utf8mb4_unicode_ci,IMPLICIT) and (utf8mb4_general_ci,IMPLICIT)

This error occurs when database tables use different character set collations.

✅ Solution:

We need to standardize all tables to use the same collation: utf8mb4_general_ci

Step 1: Access phpMyAdmin

Open your browser and navigate to:

http://localhost/phpmyadmin

Step 2: Select Database

Click on the database: 3rdparty from the left sidebar

Step 3: Run Collation Fix Script

Option A: Import SQL File

  • Click on the "Import" tab
  • Choose file: fix_collation.sql
  • Location: c:\xampp\htdocs\whiteapp1\operator_assessment\fix_collation.sql
  • Click "Go"

Option B: Run SQL Directly

  • Click on the "SQL" tab
  • Copy and paste this SQL:
-- Convert all tables to utf8mb4_general_ci ALTER TABLE `operator_assessments` CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci; ALTER TABLE `operator_equipment` CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci; ALTER TABLE `operator_documents` CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
  • Click "Go"

Step 4: Run Exam Module SQL

After fixing the collation, now run the exam module SQL:

  • Stay in the "SQL" tab or go to "Import"
  • Import or paste contents of: add_exam_module.sql
  • Click "Go"

Step 5: Verify Tables

Check that these tables now exist:

  • ✅ operator_assessments - Should have new exam columns (exam_status, exam_score, etc.)
  • ✅ operator_exam_answers - New table for storing exam answers

✅ All Done!

The collation error should now be fixed. You can now use the operator assessment module with the written exam feature.

Go to Assessment List

🔍 Why This Happened

The original operator assessment tables were created with utf8mb4_unicode_ci collation, but your existing database uses utf8mb4_general_ci. When MySQL tries to join or compare data between tables with different collations, it throws this error.

The fix: We converted all tables to use the same collation (utf8mb4_general_ci) so they can work together seamlessly.
