🚀 Operator Assessment Module - Database Setup

⚠️ Important: Please complete this database setup before using the Operator Assessment module.

Step 1: Access phpMyAdmin

Open your browser and navigate to:

http://localhost/phpmyadmin

Login with your MySQL credentials (default: username: root, password: empty)

Step 2: Select Database

Click on the database: 3rdparty from the left sidebar

Step 3: Import SQL File

Option A: Import via phpMyAdmin

  • Click on the "Import" tab at the top
  • Click "Choose File" and select: setup_operator_assessment.sql
  • Location: c:\xampp\htdocs\whiteapp1\operator_assessment\setup_operator_assessment.sql
  • Click "Go" at the bottom

Option B: Run SQL Directly

  • Click on the "SQL" tab at the top
  • Open the file setup_operator_assessment.sql in a text editor
  • Copy all the SQL content
  • Paste it into the SQL query box
  • Click "Go"

Step 4: Verify Tables Created

After running the SQL, you should see three new tables:

  • ✅ operator_assessments - Main assessment records
  • ✅ operator_equipment - Equipment details
  • ✅ operator_documents - Document uploads

Check the left sidebar to confirm these tables exist.

✅ Setup Complete! You can now use the Operator Assessment module.

🔧 Troubleshooting

Issue: Tables not showing up

Solution: Refresh phpMyAdmin or check for SQL errors in the import log

Issue: Permission denied for uploads

Solution: Ensure uploads/operator_assessments/ folder has write permissions
